# PG-Life 🏠

PG-Life is a responsive web application designed to help students and working professionals find suitable PG (Paying Guest) accommodations easily.  
The project provides a clean user interface for browsing PGs, viewing details, and exploring accommodation options in different cities.

---

## 🚀 Features

- Responsive homepage design
- City-wise PG listings
- PG detail pages
- Modern and clean UI
- Mobile-friendly layout
- Interactive frontend using JavaScript

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
